# 8bit-ui Site

Next.js static site scaffold for:

- Marketing homepage
- Documentation pages sourced from the repository-level `/docs` directory

## Run locally

```bash
pnpm install
cd apps/site
pnpm dev
```

## Build static output

```bash
pnpm install
cd apps/site
pnpm build
```

The static files are generated in `apps/site/out`.
