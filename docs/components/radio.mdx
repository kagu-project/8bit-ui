# Radio

Use `Radio` for single-choice selection within a named group.

## Import

```tsx
import { Radio } from '@kagu-project/8bit-ui';
```

## Basic Usage

<div className="preview previewStack">
  <Radio name="difficulty-preview" value="easy" label="Easy" defaultChecked />
  <Radio name="difficulty-preview" value="hard" label="Hard" />
</div>

```tsx
import { useState } from 'react';

const [value, setValue] = useState('easy');

<>
  <Radio
    name="difficulty"
    value="easy"
    label="Easy"
    checked={value === 'easy'}
    onChange={() => setValue('easy')}
  />
  <Radio
    name="difficulty"
    value="hard"
    label="Hard"
    checked={value === 'hard'}
    onChange={() => setValue('hard')}
  />
</>;
```

## Key Props

- `label`: optional label content
- `checked`: controlled checked state
- `name`: required for grouping
- `disabled`
- Plus native radio input props

## Accessibility

- Radios in a set must share the same `name`.
- Wrap related radios in a semantic group (`fieldset` + `legend`) when possible.
